# DataShow 功能展示 vault

> 本 vault 是**干净提交库**，只用于版本提交；日常在 Obsidian 中验收请用 `../test-vault-local/`
> （两者预置看板一致，本地测试产生的改动不会影响本 vault）。
>
> **DSQL v2.0 标记语法**：关键词用 `**` 包裹（如 `**SELECT**`）、运算符用 `%` 包裹（如 `%==%`）、
> 字符串用单引号 `'值'`、路径用双引号 `"文件夹"`。视图关键词为 `**TABLE_VIEW**` /
> `**LIST_VIEW**` / `**CARD_VIEW**`（旧 `**TABLE**` / `**LIST**` 已废除）。完整规范见
> [`../docs/DSQL-语言规范.md`](../docs/DSQL-语言规范.md)。

## 面板与侧栏操作（搜索与导出）

- **侧栏搜索栏**：侧栏顶部输入框按「分类名 / 看板名」过滤（不区分大小写子串）；点「搜索」或回车应用，点「清空」恢复全部；折叠状态保留，无匹配的分类隐藏，全不匹配显示「没有匹配的看板」。
- **通用搜索**：面板工具条「🔍 搜索...」对表格 / 列表 / 卡片三视图统一生效，匹配文件标题 + 列名 + 列值；搜索词在切视图时保留。
- **结果导出**：面板工具条右侧「导出路径（vault 相对路径）」+「导出」按钮，把当前结果导出为 `.json` / `.csv`（自动建目录；拒绝 `..` 越界 / 绝对路径 / `.xlsx`）；导出内容含搜索过滤后的行。

## 可复制示例（跨文件关系与逻辑判断）

**跨文件正向关系：谁链接了「张三」（`file.outlinks`）**

```sql
**TABLE_VIEW** **SELECT**
  file.name **AS** 人物,
  阵营,
  身份,
  **length**(file.outlinks) **AS** 出链数
**FROM** "示例/人物关系示例"
**WHERE** **contains**(file.outlinks, "示例/人物关系示例/张三.md")
**SORT** 阵营 **ASC**
```

命中：李四、王五、孙七。把 `file.outlinks` 换成 `file.inlinks` 即为**反向反查**（谁链接了张三）。

**跨文件 + 逻辑取反：出链命中「王五」且未阵亡**

```sql
**TABLE_VIEW** **SELECT**
  file.name **AS** 人物,
  阵营,
  身份,
  **length**(file.outlinks) **AS** 出链数
**FROM** "示例/人物关系示例"
**WHERE** **contains**(file.outlinks, "示例/人物关系示例/王五.md") **AND** **NOT** (状态 %==% '阵亡')
**SORT** 阵营 **ASC**
```

命中：张三、赵六、孙七（王五本人未引用自己，且已阵亡）。

**AND 优先于 OR，括号可覆盖**

```sql
**TABLE_VIEW** **SELECT**
  file.name **AS** 人物, 阵营, 身份, 年龄
**FROM** "示例/人物关系示例"
**WHERE** 阵营 %==% '中立' **OR** 阵营 %==% '天枢' **AND** 身份 %==% '谋士'
**SORT** 阵营 **ASC**
```

命中：孙七（中立）、李四（天枢谋士）——等价于 `中立 OR (天枢 AND 谋士)`；
写成 `(阵营 %==% '天枢' **OR** 阵营 %==% '幽篁') **AND** 状态 %==% '存活'` 则命中张三、李四、赵六。

**跨文件夹：场景侧反查人物（`示例/场景示例/` → 人物）**

```sql
**TABLE_VIEW** **SELECT**
  file.name **AS** 场景,
  类型,
  地点,
  **length**(场景人物) **AS** 出场人数
**FROM** "示例/场景示例"
**WHERE** **contains**(场景人物, '张三')
**SORT** 地点 **ASC**
```

命中：赤壁、长坂坡（`场景人物` 是 frontmatter 数组，`**contains**` 对数组做严格相等匹配）。

**跨文件夹：人物侧反查场景（人物 ← `示例/场景示例/`）**

```sql
**TABLE_VIEW** **SELECT**
  file.name **AS** 人物,
  阵营,
  身份,
  **length**(file.inlinks) **AS** 被引用次数
**FROM** "示例/人物关系示例"
**WHERE** **contains**(file.inlinks, "示例/场景示例/长坂坡.md")
**SORT** 阵营 **ASC**
```

命中：张三、王五。查「同时出现在长坂坡或幽篁大营」只需把两个 `**contains**` 用 `**OR**` 连起来
（命中张三、王五、赵六）。

**场景 + 逻辑取反：含张三且结果不是僵持**

```sql
**TABLE_VIEW** **SELECT**
  file.name **AS** 场景, 类型, 地点, 结果
**FROM** "示例/场景示例"
**WHERE** **contains**(场景人物, '张三') **AND** **NOT** (结果 %==% '僵持')
**SORT** 地点 **ASC**
```

命中：长坂坡（赤壁因结果为「僵持」被 `**NOT**` 剔除）。

## 可复制示例（DSQL 1.5）

**汇总行（TOTAL 计数与求和 + 派生均价：汇总值随行并列展示）**

```sql
**TABLE_VIEW** **SELECT**
  **TOTAL** 1 **AS** $笔记数$,
  **TOTAL** 价格 **AS** $总价格$,
  ($总价格$ %/% $笔记数$) **AS** $均价$
**FROM** "示例/数学示例"
```

> `**SELECT**` 全部为 TOTAL / 裸槽位项时才合成单行「汇总」结果；本示例含派生列 `$均价$`，
> 故按行输出、汇总值逐行并列展示（`$均价$` 为全表口径，每行相同）。

**占比（TOTAL 恒忽略 WHERE：WHERE 只过滤显示行，聚合仍是全表口径）**

```sql
**TABLE_VIEW** **SELECT**
  file.name **AS** 名称,
  价格,
  **TOTAL** 价格 **AS** $全表总价格$,
  (价格 %/% $全表总价格$) %*% 100 **AS** $占比$
**FROM** "示例/数学示例"
**WHERE** 价格 %>=% 7
**SORT** 价格 **DESC**
```

**三值展示（DSQL 1.5：三种「无」互不混淆；缺失字段显示为 —）**

```sql
**SELECT** file.name **AS** 名称, 数量, 价格, 开关
**FROM** "示例/三值示例"
**SORT** 价格 **DESC**
```

三行全部输出：`数量` 在正常零值行为 `0`、另两行因字段缺失显示为 `—`；
**注意**：若改用 `**WHERE** 数量` 过滤，三行都会被剔除（0 / null / null 在裸真值判断中均为假）。

**empty 谓词与三值传播**

```sql
**SELECT** file.name **AS** 名称,
  **empty**(未填) **AS** 未填是empty,
  **empty**(备注) **AS** 空串是empty,
  未填 %+% 1 **AS** empty算术
**FROM** "示例/三值示例"
**SORT** 价格 **DESC**
```

`**empty**()` 仅认「未赋值」；`""` / `[]` / `0` / `false` / null / 缺失字段均为 false。

## 可复制示例（[ext] 后缀过滤）

数据在 `示例/日志示例/`（md + txt + log + 3 个损坏文件），九个演示看板在侧栏「ext示例」分类。

**并置简写（`[ext]` 后紧跟条件 ≡ 隐式 `**AND**`，语法定稿示例）**

```sql
**TABLE_VIEW** **SELECT**
  status **AS** 状态,
  level **AS** 级别,
  file.ext **AS** 后缀
**FROM** "示例/日志示例"
**WHERE** [txt, log] status %!=% 'error'
**SORT** priority **ASC**
```

命中：app.txt、sub/网关.log 两行（db.txt 被 `status %!=% 'error'` 过滤，md 被 `[txt, log]` 行级排除）；
三个损坏文件在结果区尾部渲染为「解析失效 3」（UTF-8 字节序，默认上限 3 可在设置调整）。

**`[]` 全量读取（三态之 ALL，含子目录）**

```sql
**SELECT** file.name **AS** 文件, status **AS** 状态, file.ext **AS** 后缀
**FROM** "示例/日志示例"
**WHERE** []
**SORT** file.ext **ASC**
```

命中 4 行：`服务日志.md`（官方路径）+ app.txt / db.txt / 网关.log（自研解析）；
损坏文件剔除并计数，查询继续。

**`[txt] OR status %==% '正常'`（OR 意图保留：按行判断，不用并集偷懒）**

```sql
**SELECT** file.name **AS** 文件, status **AS** 状态, file.ext **AS** 后缀
**FROM** "示例/日志示例"
**WHERE** [txt] **OR** status %==% '正常'
```

命中 4 行：全部 txt 行（app、db）+ 满足 status 的 md 行与 log 行。
对照：`[] **AND** **NOT** [txt]` 只剩 md + log 两行；`[txt] **AND** [mp4]` 为空结果。

**验收要点**：不写 `[...]` 的查询行为与旧版完全一致（零触发）；`**FROM** #log` 这类标签源
不触发非 md 读取（`**WHERE** [txt]` 得 0 行属预期）；`**TOTAL**` 在含 `[ext]` 的查询中仍只
统计 FROM 全量命中行（含 `[ext]` 非 md 行，恒忽略 WHERE）：`**TOTAL** priority` = 1+2+3 = 6；
改 `app.txt` 内容后面板约 300ms 自动重跑（查询级刷新兜底）。

## 可复制示例（SEARCH 正文抽取）

数据在 `示例/文章示例/`（章节行 + `[标题]` 标记 + `【状态】/【字数】` GN 字段），九个演示看板在侧栏「search示例」分类。

**章节与标题抽取成列（捕获组取 m[1]）**

```sql
**TABLE_VIEW** **SELECT**
  file.name **AS** 文件,
  章节号,
  标题
**FROM** "示例/文章示例"
**WHILE** [0, 1]
**SEARCH**
  '第([一二三四五六七八九十百\d]+)章' **AS** 章节号,
  '\[(.+?)\]' **AS** 标题
**SORT** file.name **ASC**
```

md 行 4 行：斗破苍穹（一 / 名场面）、凡人修仙传（2 / 经典），无匹配行显示 —（null）。
无 `[ext]` 时 txt 不在行集；加 `**WHERE** [txt, md]` 即接入网文摘录.txt（第3章）。

**GN 自定义字段（跨行正则，含 WHERE / 数值排序）**

```sql
**SELECT**
  file.name **AS** 文件,
  状态,
  字数
**FROM** "示例/文章示例"
**WHERE** [txt, md] **AND** 状态 %==% '连载中'
**WHILE** [0, 1]
**SEARCH**
  '【状态】\s*\n\s*(.+)' **AS** 状态,
  '【字数】\s*\n\s*(\d+)' **AS** 字数
**SORT** 字数 %+% 0 **DESC**
```

命中：追更记录.txt（连载中 / 999）。`字数` 抽出字符串 `"999"`，`%+% 0` 走 §6.3 补丁隐式转数字。

**验收要点**：SEARCH 是子句不是函数（写进 WHERE / SELECT 表达式直接报错）；DSQL 2.4 起 SEARCH 必须由
`**WHILE**` 驱动（仅写 SEARCH → parse 期致命报错「**SEARCH** 需要 **WHILE**」）；别名与 SELECT 别名
同名 → parse 期冲突，与现有字段同名 → prepare 期冲突；无匹配 / 无 body → null（显示 —，不是空串）；
`**TOTAL**` 在含 SEARCH 的查询中基于 FROM 全量命中行（聚合遍在 SEARCH 之后，数值抽取字段可被聚合，
字符串按 §6.3 隐式转数值）。

**分类计数（COUNT 填充槽位；WHERE 收窄口径）**

```sql
**SELECT**
  **TOTAL** 1 **AS** $全量$,
  $过滤文件数$
**FROM** "示例/文章示例"
**WHERE** [txt]
**COUNT** true %==% true **AS** $过滤文件数$
```

两口径同板：`$全量$` = 6（TOTAL 恒 FROM 全量）；`$过滤文件数$` = 2（WHERE 后行集，
`true %==% true` 恒真惯用法即 SQL `COUNT(*)`）。`**COUNT**` 的 `**AS**` 强制 `$槽位$`
且须在 SELECT 声明裸槽位（DSQL 2.3 槽位模型）；`**TOTAL**` 的 `**AS**` 同样强制 `$槽位$` 写法。

## 可复制示例（WHILE 循环驱动，DSQL 2.4）

数据在 `示例/待办示例/`（正文含 `- [ ] xxx` 待办行）、`示例/多变量抽取示例/`（3 段重复字段块）、
`示例/文章示例/`（章节行 + `[标题]` 标记），十个演示看板在侧栏「WHILE示例」分类。

**逐轮抽取待办（轮数 = 结束 − 起始，匹配不足补 null）**

```sql
**TABLE_VIEW** **SELECT**
  file.name **AS** 文件,
  待办
**FROM** "示例/待办示例"
**WHILE** [0, 3]
**SEARCH** '- \[ \] (.+)' **AS** 待办
**WHERE** 待办 %!=% null
```

`**WHILE** [0, 3]` 把每篇纪要展开为 3 轮，SEARCH 游标逐轮推进取第 1 / 2 / 3 条待办；
某轮无匹配即补 null，`**WHERE** 待办 %!=% null` 只留真正命中的行（null 行被 WHERE 滤掉）。

**TOTAL 全量 vs COUNT 有效（两口径同板）**

```sql
**TABLE_VIEW** **SELECT**
  **TOTAL** 1 **AS** $全量槽位$,
  $有效待办$
**FROM** "示例/待办示例"
**WHILE** [0, 3]
**SEARCH** '- \[ \] (.+)' **AS** 待办
**COUNT** 待办 %!=% null **AS** $有效待办$
```

`$全量槽位$` = WHILE 展开后的全量命中行数（不含 WHERE，含 null 填充行）；`$有效待办$` =
WHERE 过滤后计数。两口径之差即「补 null 的未命中轮数」。

**语法变体（8 板，实测输出见括注）**

```sql
-- ① 子句自由穿插：前件只讲依赖序、不讲书写紧邻（SORT 在 WHILE 前、WHERE 在 WHILE 后均合法）
**TABLE_VIEW** **SELECT** file.name **AS** 文件, 待办
**FROM** "示例/待办示例"
**SORT** file.name **ASC**
**WHILE** [0, 3]
**WHERE** 待办 %!=% null
**SEARCH** '- \[ \] (.+)' **AS** 待办
-- 实测 4 行：例会纪要 3 条（确认下次迭代范围 / 补齐 DSQL 用例 / 更新 README）+ 评审纪要 1 条

-- ② 省略 SELECT（自动列 = 结果行字段并集，UTF-8 字节序）+ WITHOUT ID 任意位置
**FROM** "示例/多变量抽取示例"
**WHILE** [0, 5]
**SEARCH**
  '姓名：(.+)' **AS** 姓名,
  '阵营：(.+)' **AS** 阵营
**WHERE** 姓名 %!=% null
**WITHOUT** **ID**
-- 实测 3 行：张三|天枢、李四|幽篁、王五|天枢

-- ③ 派生变量链：SEARCH 抽取的行字段可参与 SELECT 表达式，`expr **AS** $变量$` 进变量表供更晚列引用
**TABLE_VIEW** **SELECT**
  姓名, 年龄,
  年龄 %+% 1 **AS** $明年$,
  $明年$ %*% 2 **AS** $两年合计$
**FROM** "示例/多变量抽取示例"
**WHILE** [0, 5]
**SEARCH**
  '姓名：(.+)' **AS** 姓名,
  '年龄：(\d+)' **AS** 年龄
**WHERE** 年龄 %!=% null
-- 实测 3 行：张三 28 / 29 / 58、李四 35 / 36 / 72、王五 22 / 23 / 46

-- ④ 偏移区间 + COUNT 多槽位：起始绝对值不影响结果（[2, 5] ≡ [0, 3]，同为 3 轮）
**TABLE_VIEW** **SELECT** **TOTAL** 1 **AS** $全量$, $有名字$, $有阵营$
**FROM** "示例/多变量抽取示例"
**WHILE** [2, 5]
**SEARCH**
  '姓名：(.+)' **AS** 姓名,
  '阵营：(.+)' **AS** 阵营
**COUNT** 姓名 %!=% null **AS** $有名字$, 阵营 %!=% null **AS** $有阵营$
-- 实测 1 行（SELECT 仅槽位 + TOTAL → 单行合成）：3 | 3 | 3
```

另有 4 板同属语法变体：列表视图多轮展开（`**LIST_VIEW**`，输出同上①）、
`[ext]` 非 md 多轮 + LIMIT（`**WHERE** [txt, md]` 接入 txt，实测 3 行：凡人修仙传|2、斗破苍穹|一、网文摘录|3）、
TOTAL 求和多轮抽取的数字串（`**TOTAL** 年龄` = 28+35+22 = 85，逐行重复显示）、
排序·SEARCH 字段自定义优先级（`**SORT** 阵营 **BY** ('天枢', '幽篁'), 姓名 **ASC**`）。

> **N 与字段数无关**：`**WHILE** [起始, N]` 的轮数只由边界之差决定，与 SEARCH 写几组正则无关——
> 多字段是「同一轮内多模板各取一个匹配」，不因字段数增大 N。多条 `**WHILE**` / `**SEARCH**` 子句
> **不支持**（重复即 parse 期致命「子句重复出现」），多字段需求由单条 SEARCH 的多个 `search_item` 覆盖。

**验收要点**：`**WHILE**` 是独立顶层子句，非 SEARCH 修饰符；前件为 FROM，SEARCH 的前件为 WHILE
（两者必须成对：仅 WHILE 无 SEARCH → 报错，仅 SEARCH 无 WHILE → 报错）；边界须为非负整数字面量且
起始 < 结束，parse 期校验（否则 parse 期致命）；无循环索引变量；执行位置在 FROM / [ext] 之后、聚合遍之前
（即 `FROM → [ext] → WHILE+SEARCH → 聚合遍(TOTAL) → WHERE → COUNT → SORT → LIMIT → SELECT`）。

## 可复制示例（审查修复对照，DSQL 2.3.1）

数据在 `示例/审查修复示例/`（溢出与一元 + 重复键对照 + 顶层列表），四个演示看板在侧栏「审查修复示例」分类。

**溢出守卫与一元正负号**

```sql
**TABLE_VIEW** **SELECT**
  名称,
  超大 %/% 微小 **AS** 溢出除法,
  超大 %*% 超大 **AS** 溢出乘法,
  %-%数字串 **AS** 一元减数字串,
  %-%数值 **AS** 一元减数值,
  数字串 %+% 0 **AS** 二元转换对照
**FROM** "示例/审查修复示例"
**SORT** 名称 **ASC**
```

`1e308 %/% 1e-308` 与 `1e308 %*% 1e308` 结果为 —（非有限数 → null，开调试可见警告）；
一元 `%-%` 仅作用于数值：`%-%数字串` → —（不计警告）、`%-%数值` → -5；
对照 `数字串 %+% 0` → 5（二元算术按 §6.3 ③ 隐式转数字，与一元口径不同）。

**重复键剔除与顶层列表对照**

```sql
**TABLE_VIEW** **SELECT**
  file.name **AS** 文件,
  名称,
  数值
**FROM** "示例/审查修复示例"
**SORT** 文件 **ASC**
```

只出现「溢出与一元」「顶层列表」两行：「重复键对照.md」的 frontmatter 含真重复键「数值」，
按 §6.1 容错规则整篇剔除（开调试可见字段名为「数值」的 `duplicateKey` 警告——修复前曾误报
「- 备选一」并把「顶层列表.md」一并剔除）；「顶层列表.md」正常进入结果，仅 `file.*` 列有值。

**`[ext]` 并置简写与 `**NOT**`**

```sql
**TABLE_VIEW** **SELECT**
  file.name **AS** 文件, status **AS** 状态, level **AS** 级别
**FROM** "示例/日志示例"
**WHERE** [txt] **NOT** status %==% '正常'
**SORT** 文件 **ASC**
```

命中 db.txt（app.txt 因 `status %==% '正常'` 被 `**NOT**` 排除）；该写法与显式
`[txt] **AND** **NOT** status %==% '正常'` 同构（修复前报「多余的查询子句」）。

**语法收紧演示（预期报错，非可用看板）**：看板「修复·语法收紧演示」的 SQL 为
`**SORT** status **DESC** **DESC**`，故意触碰「方向修饰符至多一次」（§3），
面板按 parse 期致命错误渲染，用于验收报错行为。

## 操作

1. 设置 → DataShow → 看板：查看/增删看板（名称/分类/说明 + 视图模式）；
2. 左侧栏 DataShow 图标打开看板侧栏（按分类分组），点击看板在主工作区打开面板；
3. 面板 DSQL 编辑框可直接改查询（防抖自动保存），「刷新」手动重跑，「视图」下拉切换
   跟随语句 / 表格 / 列表 / 卡片（强制覆盖时会同步 SQL 开头关键词）；
4. **卡片视图**单击字段值直接编辑 frontmatter（派生列只读），保存后结果自动刷新；
   表格 / 列表为只读，点击行或文件名打开笔记；
5. 「查询结果 / 调试信息」标签页展示 FROM/WHERE/SORT/LIMIT 各阶段统计与 warnings（设置可关）。
